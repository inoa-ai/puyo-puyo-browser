# Puyo Browser

Browser-only falling-puyo game built with HTML, CSS, and Canvas.

Open `index.html` in a browser to play. No build step is required.

Controls:

- Enter: start
- Left / Right: move
- Up or Z: rotate
- Down: soft drop
- Space: hard drop
- P: pause

Features:

- 6 x 12 board with hidden spawn row
- falling two-puyo pieces
- wall-kick rotation
- ghost landing preview
- four-or-more connected clear rule
- gravity and chain resolution
- score, chain, level, next-pair HUD
- high score saved in the current browser
- keyboard and touch controls
